# CodeAlpha Task 1 - Web Scraping

## Project Title
Book Price and Rating Web Scraper

## Objective
This project collects book names, prices and ratings
from a public website using Python.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- CSV

## Data Collected
- Book Name
- Price
- Rating

## Website
https://books.toscrape.com/

## How to Run

Install libraries:

pip install requests beautifulsoup4

Run the program:

python scraper.py

The data is saved in:

books.csv

## Output
The scraper successfully collects book information
and stores it in a CSV file.
